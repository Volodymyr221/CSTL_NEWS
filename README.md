# CSTL LIFE

**Застосунок містечка Олика** (Волинська область, Україна, ~3 тис. жителів) —
новини, дошка оголошень, приватний чат між людьми, розклад автобусів, питання до
громади.

🌐 **[castlelife.org](https://castlelife.org)**

> 🔒 Застосунок зараз закритий заслінкою розробки (`src/core/dev-lock.js`) —
> публічний доступ відкриється перед запуском. Код відкритий.

---

## Стек

| шар | що використано |
|---|---|
| Фронтенд | **ванільний JavaScript**, без фреймворків. Збирається esbuild в один `bundle.js` |
| Оболонка | **PWA** — встановлюється на iPhone з домашнього екрана, працює офлайн через Service Worker |
| Хостинг | **GitHub Pages** (статика) + власний домен |
| Бекенд | **Supabase**: Postgres, Auth (Google OAuth), Row Level Security, Storage, 6 Edge Functions на Deno |
| Дані контенту | JSON-файли в репозиторії (`data/`), оновлюються парсерами через GitHub Actions |
| CI/CD | 9 workflow: деплой, парсер новин, парсер автобусів, бекап бази, скан секретів |

**Свого сервера немає.** Уся серверна логіка — це або SQL-функції в Postgres, або
Edge Functions. Ключ Supabase у `bundle.js` публічний за призначенням, тому
**RLS — єдиний рубіж захисту даних**.

## Запуск локально

```bash
npm install       # esbuild + playwright
node build.js     # src/ → bundle.js
python3 -m http.server 8000    # або будь-який статичний сервер
```

Відкрити `http://localhost:8000`. ⚠️ Заслінка розробки **не діє на localhost** —
локально застосунок відкривається одразу.

```bash
npm test                          # усі стенди (потрібен Chromium)
node tests/news-widget.mjs        # один стенд
python3 scripts/test_fulltext.py  # Python-стенди запускаються окремо
```

## Дві особливості, які варто пояснити одразу

### 1. `bundle.js` закомічений у git — це навмисно

Зазвичай артефакти збірки не тримають у репозиторії. Тут вони лежать свідомо:
GitHub Pages роздає **статику**, і хоча CI перезбирає `bundle.js` при кожному
деплої, наявність файлу в git дає точку відкату, якщо збірка зламається.

### 2. Дуже багато коментарів — це основний носій знань проєкту

**32% рядків у `src/` — пояснення** (7 942 з 24 465). Це не описи «що робить
код», а відповіді на питання **чому саме так**:

- чому обрано це значення, а не сусіднє (з числами замірів);
- що вже пробували і **чому відкотили**;
- де перевірка колись **збрехала** і як це виявили.

Приклад із `src/core/list-patch.js`: пояснення, чому потрібен власний якір
прокрутки, а не браузерний `overflow-anchor` — бо в Safari його немає, і перша
версія стенда через це «довела», що бага не існує.

Такий стиль обрано тому, що проєкт веде одна людина разом з AI-асистентом, і
контекст рішень інакше втрачається між сесіями.

## Тестування

**72 браузерні стенди** (Playwright, Chromium) + Python-стенди для парсерів.

Особливість підходу: більшість стендів мають **контрольну перевірку** — вони
доведені падінням на коді *до* виправлення. Наприклад:

```bash
BUNDLE_REV=origin/main CSS_REV=origin/main node tests/news-widget.mjs
# на старому коді мусять упасти рівно ті перевірки, що описують нову поведінку
```

Це рятує від найчастішої проблеми: тест, який зелений завжди і тому нічого не
стереже. У документації проєкту зафіксовано **16 випадків**, коли перевірка
брехала — і як це виявили.

## Безпека

- **RLS увімкнено на всіх таблицях**; знімок 90 живих політик — `scripts/RLS_SNAPSHOT.md`
- Права адміністратора — через `is_admin()`, таблиця `admins` не дає самододавання
- Приватне листування закрите двома шарами: політика (хто торкається рядка) +
  тригер (які поля можна змінити)
- Динамічного SQL немає ніде — жодного `EXECUTE`
- `gitleaks` сканує репозиторій на секрети при кожному пуші
- Щоденний **шифрований** бекап бази (репозиторій публічний)

Розбір за п'ятьма класами вразливостей — у журналі сесії від 13.08.

## Що варто знати, якщо будете читати код

- **Назви вкладок не збігаються з іменами в коді.** Вкладка «Стрічка» має
  внутрішнє ім'я `shotam`, а її код лежить у `src/tabs/feed.js`.
- **Найбільші файли** — `tabs/feed.js` (244 КБ) і `tabs/board.js` (240 КБ). Так
  сталося історично; розбиття заплановане, але не перед запуском.
- **Документація українською** — проєкт локальний, і робоча мова саме така.
- Головні документи: `CLAUDE.md` (правила й карта файлів),
  `CSTL NEWS VOVA/START_HERE.md` (поточний стан), `docs/ARCHITECTURE.md`.
