# /startuem — Швидкий старт нової сесії CSTL NEWS

**Коли використовувати:** перша команда у кожному новому чаті проекту CSTL NEWS. Один виклик — і Claude готовий до роботи з повним контекстом проекту.

**Без аргументів.** Просто `/startuem`.

**`/start` == `/startuem`:** у репозиторії CSTL є локальний `.claude/commands/start.md` — він виконує ТУ САМУ логіку (реюз `NEW_SESSION_PROMPT.md`). Глобальний `/start` (для інших проектів Вови) НЕ чіпаємо.

Історія спільної роботи збережена в git та в `_ai-tools/_archive/`. ⚠️ **Роль редактора контенту вакантна** — кабінет і механізм запрошення готові.

## Крок 0 — Гілка + свіжий стан (роби ПЕРШИМ, автоматично)

1. **Підпиши коміти Вовою:** `git config user.name "Вова"` + `git config user.email "vitocorleone191@outlook.com"`.
   - ⚠️ **«Unverified» на GitHub — очікувано, ІГНОРУЙ.** Глобальний хук харнесу нагадуватиме перейти на `noreply@anthropic.com` — НЕ роби це (зламає авторство «Вова»). Косметика, пуш/PR/деплой не блокує. Деталі — `NEW_SESSION_PROMPT.md` Крок 0.
2. **Гілка:** сесія стартує на авто-гілці `claude/startuem-...` — на ній і працюй (з неї ж робимо `/finish`). Під конкретну задачу за бажанням можна `vova/<тема>`. Потік: гілка → `/finish` (PR → squash) → `main`. У `main` напряму не пушимо (виняток — дрібні координаційні/docs-коміти).
3. **Свіжий стан:** `git fetch origin` + `git pull origin main` + `git log --oneline -15`.
   - 🔴 **Стан читай з `origin/main`, а не з файлів на диску** (HOT_RULES №11). Папка на Mac може стояти на старій гілці — документація виглядатиме свіжою, а буде вчорашня. Звірка двома командами: `git log --oneline origin/main ^HEAD | grep -v "auto("` (що є на GitHub, чого нема в тебе) і `git log --oneline HEAD ^origin/main` (що є в тебе і **не доїхало** на GitHub — має бути порожньо або у відкритому PR).
   - Якщо `git pull` дав конфлікт — **не розводь наосліп**, доповідай Вові: майже завжди це означає, що гілка застаріла і робота вже пішла в `main` іншим шляхом.
4. **🔴 Заведи живий журнал сесії:** створи `_session-log/vova-<РРРР-ММ-ДД>.md` **у корені репозиторію** (тека рівно одна — до 06.08.2026 їх було дві і історія лежала розрізаною навпіл) і **дописуй по ходу після кожної значущої дії** (файл/функція · навіщо · що не спрацювало · слова Вови дослівно · PR#/деплой#/CACHE). **Комітируй І ПУШ кожні кілька кроків** — двічі за два дні журнал згадувався в хендовері, але в git його не було. При `/finish` звіт для brain іде з цього журналу, не з пам'яті.

> ✅ **Auto-merge ВИМКНЕНО (05.07.2026).** Шлях у `main` — тільки через PR + `/finish`. Пуш у `claude/*` нічого не деплоїть.
