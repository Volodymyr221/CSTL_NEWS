# /qa-explore — Браузерний смоук-тест

## Що це
Claude сам збирає застосунок **локально**, запускає headless-браузер (без вікна, Playwright) і
проходить екрани як живий користувач — ловить падіння, помилки консолі, биту верстку.
Знімки екрана + короткий звіт. **НЕ замінює ручний тест власника на його пристрої.**

## Рівні
- **Quick** — головний екран + 1 зачеплена вкладка (дрібний фікс)
- **Standard** — усі зачеплені екрани + ключові дії/модалки (3-6)
- **Exhaustive** — усі екрани, шлях користувача, перед великим релізом

## Передумови
1. `npm install` (у devDependencies `@playwright/test`).
2. Знайти вже наявний браузер у середовищі (`ls /opt/pw-browsers/`) і використати як
   `executablePath`. **Не качати браузер заново.**

## Прогін
1. Зібрати + підняти **локально** (ніколи не тестувати прод):
   ```
   node build.js ; python3 -m http.server 4173 &
   ```
2. **Прочитати РЕАЛЬНИЙ код навігації** — знайти функцію перемикання екранів і список екранів.
   **НЕ хардкодити** — брати з коду.
3. Написати **разовий** скрипт у тимчасову теку (**НЕ в репозиторій**): відкриває локальну адресу ·
   слухає `pageerror` + `console.error` увесь час · проходить екрани за рівнем · знімок до/після ·
   за потреби відкриває ключові модалки.
4. Зібрати помилки + знімки.

## Звіт
Один рядок: «🔍 Браузер-смоук [рівень]: N екранів · 0 падінь · консоль чиста · верстка ок».
Проблемні знімки — показати власнику. Перевірене позначити «✅ браузер-смоук».

## Fail-soft
Браузер не запускається в цьому середовищі — **не блокувати**: «смоук недоступний, зроблено
`node --check`; перевір вручну». Тест — помічник, не ворота.

## Межі
Не замінює ручний тест: жести, гумове прокручування, встановлений застосунок, реальні
сповіщення, поведінка клавіатури на телефоні — лишається на власнику.
