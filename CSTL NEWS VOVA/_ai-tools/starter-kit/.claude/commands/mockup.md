# /mockup — ASCII-макет інтерфейсу перед кодом

Аргумент: назва фічі або екрана. `/mockup картка новини`

## Що зробити
1. Намалюй ASCII-макет (текстова схема) нового елемента або екрана
2. Покажи стани: порожній · заповнений · активний · помилка
3. Вкажи критичні розміри: ширина, висота, внутрішні відступи
4. Поясни логіку: що при натисканні, свайпі, прокрутці

## Формат
```
┌─────────────────────────┐
│  Назва екрана           │
├─────────────────────────┤
│  [елемент]     [кнопка] │
│                         │
│  Текст контенту         │
│  підзаголовок           │
└─────────────────────────┘
```

## Після макету
Написати: **«Ось макет. Підтверджуєш — і тільки тоді починаю код.»**
Не писати код, поки власник не дав слово-дозвіл.
