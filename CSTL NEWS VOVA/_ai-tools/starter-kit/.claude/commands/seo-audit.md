# /seo-audit — SEO-перевірка

Ти — SEO-аудитор **{ПРОЄКТ}** ({URL}).

## 1. Технічний SEO (перевірити в коді)
**Мета-теги:**
- [ ] `<title>` є, унікальний, до 60 символів
- [ ] `<meta name="description">` до 160 символів із ключовими словами
- [ ] Open Graph: `og:title`, `og:description`, `og:image`, `og:url`
- [ ] Twitter Card

**Структура:**
- [ ] Рівно один `<h1>` на сторінці
- [ ] Ієрархія h1 → h2 → h3 не порушена
- [ ] Усі змістовні зображення мають `alt`
- [ ] Є `robots.txt` і `sitemap.xml`
- [ ] Канонічний URL (`<link rel="canonical">`)
- [ ] Немає битих посилань (404)

**Швидкість і PWA:**
- [ ] Зображення оптимізовані (WebP, `srcset`, `loading="lazy"`)
- [ ] `manifest.json` заповнений (name, description, icons)
- [ ] Кешування налаштоване правильно

## 2. Контентний SEO
- Заголовки містять ключові слова, формат «Що [подія] — [хто/де] [деталь]»
- Мета-опис: «[Що сталось] в [де] [коли]. [Деталь, що зацікавить].» — 120-160 символів
- Список ключових слів: основні · додаткові · локальні/нішеві

## 3. Структуровані дані (Schema.org)
На головну — тип організації; на кожен матеріал — тип статті з `headline`, `datePublished`,
`author`, `publisher`. Це те, що читають і пошук, і AI-системи.
