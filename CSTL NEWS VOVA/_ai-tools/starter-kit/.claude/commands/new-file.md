# /new-file — Додавання нового файлу коду

Аргумент: шлях. `/new-file src/tabs/search.js`

## Крок 0 — Перевірка на дубль (ОБОВʼЯЗКОВО)
```
grep -r "<функціональність>" src/
```
Плюс перевірити файл спільних утиліт. **Функція вже може існувати** — це найчастіша причина
розсинхрону в проєкті.

## Крок 1 — Створити файл
У правильній папці за структурою проєкту, з базовим каркасом.

## Крок 2 — Кеш (якщо є Service Worker)
Додати до списку статичних ресурсів — інакше офлайн-режим не побачить файл.

## Крок 3 — Імпорт у точку входу
Додати підключення, **дотримуючись існуючого порядку імпортів** (порядок буває значущим).

## Крок 4 — Розмітка (якщо файл не йде через збірку)
Додати підключення в HTML.

## Крок 5 — Документація
Додати рядок у таблицю **«Файлова структура»** в `CLAUDE.md` з описом відповідальності
(«за що відповідає цей файл»).

## Крок 6 — Перевірка
`node --check <файл>`
