## 🟡 ХВІСТ, ЩО ЛИШИВСЯ НА ВОВІ (крок 13 закритого потоку)

Смоук модалки погоди на iPhone. Порядок важливий — перший пункт головний:

1. **Погода взагалі вантажиться?** Запит до Open-Meteo розширено сімома полями
   (вітер, напрям, вологість, схід/захід, «відчувається» по годинах). Якщо API
   якесь не прийме — вся погода покаже «тимчасово недоступна».
   ⚠️ **Перевірити це кодом звідси НЕМОЖЛИВО:** егрес-проксі середовища блокує
   `api.open-meteo.com` (`curl` → 403, `WebFetch` → EGRESS_BLOCKED), стенди
   ходять у мок.
2. Тап по «сьогодні»: перша картка «Зараз», минулих годин немає.
3. Тап по майбутньому дню: відкривається на 07:00, повна доба гортанням.
4. Чи це той синій, який Вова хотів, і чи читомий текст.
5. **Звірка чисел** із Google/Синоптиком. Привід: 08.08 Google давав сб 24°/12°,
   ми — 25°/18°. Різниця по мінімуму 6°. Різні провайдери — різні моделі, але
   варте ока. Якщо розбіжність стала — можна пробувати інший `models=` в запиті.
