| Що | Число | Чому це проблема |
|---|---|---|
| **Теплота картки новини (R−B)** | **11** | Власний сторож проєкту `board-cream.mjs` вважає кремовим усе **>6**; `#FAF8EF` там названий «найслабшим кремовим» |
| **Контраст картка → фон екрана** | **1.093** | Дошці забракували **1.122** 28.07 як «рівно як Facebook, на межі помітності». Тут ще нижче |
| Фон картки | `#FAF8EF` | Тепле майже-біле на холодному сірому `--app-bg` (`#ECEEF1`) читається брудно-жовтим |
| Бейджів на картці | до **3** | Насичені «цукерки» 20px: бордо + помаранч + жовтий градієнт |
| Гео-бейдж у хабі | **на кожній** | У вкладці «Громада» всі картки пишуть «ГРОМАДА» — повтор активної вкладки |
| Ексклюзив | обідок 1.5px бордо | Кільце навколо картки читається як помилка/тривога, а не як «краще» |
| Картка з фото / без | 360px / 92-180px | Ритм списку рваний — висота стрибає втричі |
| Підпис джерела | 11px | Нижня межа читабельності за Apple HIG |
| Заголовок | 16px / 700 | Контраст 16.4 — добре, шкала не проблема |

⚠️ **Чесна межа виміру:** перша спроба порахувати контраст картки дала «19.7» — я міряв
проти `.nh-list`, у якого фон **прозорий**, тож формула рахувала проти чорного.
Правильне число (1.093) взяте проти фону `.nh-screen`. Знову мірка збрехала першою.

нейтральний сірий. Це РІВНО та хвороба, яку проєкт свідомо вилікував для Дошки
