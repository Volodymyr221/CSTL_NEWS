## 🔴 ЗНАХІДКА №1 — ВСІ ЦИФРИ НА ЕКРАНІ ОБРІЗАНІ НА 1000 РЯДКАХ

`admin.html:1355` — `fetchAnalyticsEvents()`:
```js
let q = supa.from('analytics_events').select('visitor_id, event_type, tab, meta, created_at');
if (sinceDays !== 'all') q = q.gte('created_at', …);
const { data } = await q.limit(20000);       // ← НЕМАЄ .order()
```
🔑 **`.limit(20000)` не діє.** У PostgREST/Supabase стоїть серверна стеля `db-max-rows`
(типово **1000**), і клієнт не може її підняти. Тобто адмінка ЗАВЖДИ отримує максимум
**1000 подій**, а рахує по них так, ніби це весь період.

**🛑 ДОКАЗ, ЯКИЙ ВИДНО БЕЗ БАЗИ — суми на екрані Вови:**
- розділи: 544 + 164 + 134 + 82 + 76 = **рівно 1000**
- пристрої: 803 + 197 = **рівно 1000**

**Заміряно SQL, і збіг із числами Вови точний:**

| що | адмінка каже | насправді в базі |
|---|---|---|
| унікальних за 7 днів | 203 | **336** |
| унікальних усього | 35 | **736** |
| подій усього | 1000 | **11 127** |

Перевірка гіпотези прямим запитом: унікальних серед **перших 1000** рядків за 7 днів =
**202** (адмінка показувала 203), серед перших 1000 за весь час = **5**.

🔑 **Ось звідки парадокс «усього менше, ніж за 7 днів»:** без `ORDER BY` для «весь час»
приходить перша тисяча НАЙСТАРІШИХ подій (липень), а там мало різних відвідувачів; для
«7 днів» — тисяча зі свіжих 1833, там їх сотні. Обидва числа неправдиві, просто по-різному.

## 🔴 ЗНАХІДКА №2 — У ТАБЛИЦІ НЕМАЄ ТОГО, НА ЧОМУ СТОЇТЬ УСЯ КОНЦЕПЦІЯ

`analytics_events` фактично має **рівно шість колонок**:
```
id · visitor_id (text) · event_type (text) · tab (text) · meta (jsonb) · created_at
```
**НЕМАЄ:** `user_id` · `session_id` · `route` · `device` · `browser` · `os` · `app_mode`.
Немає таблиць `analytics_sessions` і `analytics_errors`.

⚠️ **`visitor_id` — це `currentUserId() || getAnonId()`** (`app.js:230`), тобто в ОДНІЙ
колонці змішані UUID авторизованого і випадковий анонімний id. Одна людина до входу і
після входу — **два різні «унікальні»**. Заміряно: 726 значень схожі на UUID, 10 — ні.

📐 Тобто **сесій у системі не існує взагалі.** Усе, що Вова просить про сесії (тривалість,
медіана, 2.64 сесії/користувача, DAU/MAU, retention, LIVE) — рахувати сьогодні НЕМА З ЧОГО.
