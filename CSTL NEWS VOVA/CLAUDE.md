## Що це за проект

**CSTL NEWS** — локальна медіа-платформа, під-проект екосистеми **Olyka Castle**.

**Olyka Castle** — головний бренд/організація Вови. Названо на честь Олицького замку (англ. "Olyka Castle") — головної пам'ятки містечка Олика, Волинська область, Україна. Всі під-проекти мають у назві "CSTL" (скорочення від Castle): Smoke_Castle, Kino_Castle, CSTL NEWS.

**CSTL NEWS** — єдине місце де житель Олики знаходить:
- Ексклюзивні місцеві новини (яких немає ніде в інтернеті)
- Відібрані новини Волині та України (не весь шум, тільки важливе)
- Афішу подій регіону (включно з Kino_Castle та іншими під-проектами)
- Розклад автобусів через Олику (актуальний)

**Стек (технічний набір):**
- **Фронтенд** (те, що малюється в телефоні): ванільний JS (чистий JavaScript без фреймворків — без React/Vue), зібраний esbuild у один `bundle.js`; PWA (Progressive Web App — сайт, що встановлюється на телефон як додаток).
- **Хостинг** (де лежить сайт): GitHub Pages (безкоштовний), власний домен **`castlelife.org`** (файл `CNAME` у корені).
- **Бекенд** (серверна частина): **Supabase** — вхід через Google (`src/core/auth.js`), база даних усього, що пишуть люди (оголошення, приватний чат, коментарі, профілі), політики доступу **RLS** (Row Level Security — правила «хто які рядки бачить», діють на боці сервера), сховище фото, і чотири Edge Functions (маленькі серверні функції: `send-bus-push`, `send-chat-push`, `send-comment-push`, `send-group-push`).
- **localStorage / sessionStorage** (сховища в самому браузері) — тільки для налаштувань пристрою і чернеток, **не для контенту**.

```

    ↓
main отримує мердж-коміт
    ↓
.github/workflows/deploy.yml запускається автоматично:
  1. npm install (встановлює esbuild — збирач коду)
```

- **Не пушити в `main` напряму** з робочої сесії — тільки через PR через `/finish`.

## Система деплою (А+)

**Флоу:** пушиш у `main` → `.github/workflows/deploy.yml` автоматично:
1. `npm install` (встановлює esbuild)
2. `node build.js` (збирає `bundle.js` зі `src/`)
3. `sed` замінює плейсхолдер у `index.html` на `v{run_number} · DD.MM HH:MM` (час Києва)
4. `actions/upload-pages-artifact@v3` (завантажує весь проект як artifact)
5. `actions/deploy-pages@v4` (публікує artifact на GitHub Pages)

**URL сайту (адреса):** **`https://castlelife.org`** — основна, задана файлом `CNAME` у корені репозиторію.
`https://volodymyr221.github.io/CSTL_NEWS/` — стара технічна адреса GitHub Pages, працює як дзеркало.
⚠️ `CNAME` мусить лежати в корені й потрапляти в артефакт деплою: артефакт **і є** сайт, тож зникне файл — злетить домен (так і сталось 06.08).

**Лічильник версії** — маленький сірий текст **по центру шапки** (`.deploy-stamp`, `style/base.css`). Формат: `v{N} · DD.MM HH:MM`. Якщо після пушу число не змінилось — деплой не пройшов.

**Запуск тільки при пуші у `main`**, але можна вручну: `github.com/Volodymyr221/CSTL_NEWS/actions → Deploy CSTL NEWS → Run workflow`.

**Вимога (одноразово):** у `Settings → Pages → Source` мусить стояти "GitHub Actions" (не "Deploy from a branch").
