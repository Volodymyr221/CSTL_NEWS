# OpenMontage — система монтажу відео для креативів запуску

> Встановлено 27.09.2026. Потрібно **лише для маркетингових відео** (Instagram,
> TikTok, Facebook). До застосунку `castlelife.org` не має жодного відношення і
> в збірку сайту не потрапляє.

---

## Що це

[OpenMontage](https://github.com/calesthio/OpenMontage) — відкрита система
**агентного** (керованого ШІ-агентом) виробництва відео. Описуєш словами, який
хочеш ролик; агент сам робить сценарій, картинки, озвучку, монтаж і рендер
(фінальний прорахунок відео у файл).

Всередині: Python + FFmpeg (склейка відео), Remotion (відео на React) і
HyperFrames (відео на HTML/GSAP), Piper (безкоштовна локальна озвучка),
плюс необовʼязкові платні сервіси генерації (Kling, Runway, Veo, FLUX).

---

## Де воно лежить

`vendor/openmontage` — підключене як **git-підмодуль** (submodule: посилання на
чужий репозиторій, закріплене на конкретному коміті), а не скопійоване в нас.

**Чому саме підмодуль, а не копія файлів:**

1. **Розмір.** Робоче дерево OpenMontage — 91 МБ, 2115 файлів. Артефакт деплою
   в нас це **весь репозиторій** (`path: .`), і при 100 МБ публікація на Pages
   перестає встигати за 10 хвилин — це вже клало сайт 06.08. Підмодуль додає в
   нашу історію 4 рядки замість 91 МБ.
2. **Ліцензія.** OpenMontage під AGPLv3 — вірусна ліцензія: якщо її код влити в
   наш репозиторій, вимоги поширюються далі. Підмодуль тримає межу чіткою: їхній
   код лишається їхнім репозиторієм.
3. **Свої 138 скілів і свій `CLAUDE.md`.** У них `CLAUDE.md` наказує агенту
   читати `AGENT_GUIDE.md` перед будь-якою відповіддю, а `.claude/skills/` має
   138 скілів. Скопіюй це в корінь — і воно перебиває наші правила з
   `HOT_RULES.md` у кожній сесії. У підмодулі воно вмикається лише коли ти
   свідомо працюєш усередині цієї папки.

## Як увімкнути в новому оточенні

Свіжий клон репозиторію папку `vendor/openmontage` бачить **порожньою** — це
нормально для підмодуля. Щоб наповнити і підготувати:

```bash
# 1. Витягнути сам OpenMontage (~160 МБ разом з історією)
git submodule update --init --depth 1 vendor/openmontage

# 2. FFmpeg — обовʼязковий, без нього нічого не рендериться
sudo apt install -y ffmpeg      # Linux
# brew install ffmpeg           # macOS

# 3. Залежності OpenMontage (створює свій .venv, ~5 хв)
cd vendor/openmontage && make setup
```

Перевірка, що все стало:

```bash
cd vendor/openmontage && make preflight
```

Виводить перелік інструментів зі статусом `available` / `unavailable`.
`unavailable` у платних (Kling, Runway, ElevenLabs, Azure) — **це норма**: для
них потрібні API-ключі в `vendor/openmontage/.env`. Локальні (`ffmpeg`,
`hyperframes_compose`, `piper` TTS, аналізатори кадру і звуку) мусять бути
`available`.

Станом на 27.09.2026 в оточенні Claude Code перевірено: FFmpeg 6.1.1,
Node 22.22, Python 3.11, HyperFrames 0.8.80 — `runtime_available=True`.

## Як робити ролик

Працювати треба **з папки підмодуля**, бо там свій `CLAUDE.md` і свої скіли:

```bash
cd vendor/openmontage
```

Далі — звичайним проханням агенту, людською мовою. Приклад під наш запуск:

```
Зроби вертикальний ролик 15 секунд для Instagram Reels про вкладку
«Автобуси» застосунку CSTL LIFE. Візуал — з готових картинок
launch/creatives-v3/, озвучка українською, без платних сервісів.
```

Наші готові креативи лежать у файлах проєкту: `launch/creatives-v3/`
(6 картинок 1080×1350 + версії для Instagram у `insta/`) і генератор
`generator-v3.py`.

## Чого не робити

- 🛑 **Не додавати `submodules: true`** у `actions/checkout` в
  `.github/workflows/deploy.yml`. Артефакт стрибне 19 → 110 МБ і деплой
  перестане проходити. Рядок `vendor/openmontage` у кроці `Trim artifact`
  стоїть саме як страховка на цей випадок — не прибирати його.
- 🛑 **Не копіювати їхні `.claude/skills` чи `CLAUDE.md` у наш корінь.**
  Перебиває наші правила сесії.
- 🛑 **Не комітити `vendor/openmontage/.env`** — там місце для API-ключів.
  (Він у їхньому `.gitignore`, але перевіряй, якщо додаєш ключі.)
- 🛑 **Не тягнути це в застосунок.** Відео — це матеріал для кампанії, а не
  частина `src/`.

## Оновлення до нової версії

```bash
cd vendor/openmontage
git fetch origin main && git checkout origin/main
cd ../.. && git add vendor/openmontage
git commit -m "chore: OpenMontage оновлено до <короткий хеш>"
```

Підмодуль закріплений на коміті, тому оновлення завжди свідоме — саме по собі
воно не «приїде».
